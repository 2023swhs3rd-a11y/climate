# 🌍 기후 진로 특강 과제 「기후가 바꾸는 나의 직업 지도」

봉일천고등학교 진로 특강 「기후가 바꾸는 나의 직업 지도」의 과제를 온라인으로 쓰고 제출하는 사이트입니다.
생태탐구반 보고서([/eco-report/](https://2023swhs3rd-a11y.github.io/eco-report/))와 구조는 같고, 특강 슬라이드의 현장 미션·과제·계열별 탐구 질문으로 내용을 바꿨습니다.

- 학생용: https://2023swhs3rd-a11y.github.io/climate/
- 선생님용: https://2023swhs3rd-a11y.github.io/climate/#teacher
- 대상: 특강 참여 1·2학년

## 과제 구성

| 단계 | 이름 | 하는 일 | 선생님 확인 |
|---|---|---|---|
| ✍️ 1단계 | 직업 카드·질문 | 2040 나의 직업 카드 네 칸(직업, 기후 키워드, 2040년의 새로운 일, 이번 학기 활동) → 과제 A~D 또는 계열별 질문 고르기 → 나의 질문, 이유, 할 일 | 확인 ① |
| 🔍 2단계 | 자료 탐구 | 과제별로 꼭 찾을 것 안내, 자료 카드 1장(+선택 1장), 알게 된 사실(표·그래프), 중간 점검 | 확인 ② |
| 🧭 3단계 | 보고서·성찰 | 보고서 네 칸(나의 질문 / 찾은 자료와 출처 / 알게 된 사실 / 내 생각과 진로 연결), 달라진 생각, 직업 카드 다시 쓰기, 학과·과목, 이어 갈 창체, 다음 질문, AI 사용 기록, 스스로 평가 | 확인 ③ |

## 과제와 질문 (js/schema.js 의 `TOPICS`)

- 과제 A~D: ESG 보고서 읽기 · 우리 지역 기후 · 기사와 직업 · 진로 로드맵
- E. 계열별 탐구 질문 24개: 인문·사회 / 경영·경제 / 자연·공학 / 생명·보건 각 6개(특강 슬라이드 그대로, 카드마다 찾아볼 자료 표시)

## 처음 설정 (새 구글 시트 1개)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다(예: '기후 진로 특강 과제'). 다른 보고서 시트와 따로 둡니다.
2. 시트 → 확장 프로그램 → Apps Script → `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
3. 왼쪽 ⚙️ 프로젝트 설정 → 스크립트 속성 → `TEACHER_PASSWORD` 에 10자 이상의 교사 비밀번호를 넣습니다.
4. 함수 목록에서 `setup` 을 골라 실행하고 권한을 허용합니다('보고서', '명단' 시트가 생깁니다).
5. 배포 → 새 배포 → 유형: 웹 앱 → 실행: 나, 액세스: 모든 사용자 → 배포 → 웹 앱 주소를 복사합니다.
6. 이 저장소의 `js/config.js` 의 `API_URL` 에 주소를 넣습니다. 비워 두면 미리보기 모드(이 기기에만 저장, 교사 비밀번호 `demo`)로 동작합니다.
7. '명단' 시트에 참여 학생의 학번·이름을 넣어 두면 명단에 있는 학생만 들어올 수 있습니다(권장). **명단은 이 공개 저장소에 올리지 않습니다.**

코드를 바꾼 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 누릅니다. 새 배포를 만들면 주소가 바뀝니다.

## 파일

| 파일 | 내용 |

| `index.html` | 화면 틀(보안 정책, 미리보기 정보) |

| `js/samples.js` | 교사 화면 '완성 예시' 학생 2명과 진로활동 특기사항 예시 |

## 보안·개인정보

- 교사 비밀번호는 코드가 아니라 Apps Script 스크립트 속성에만 둡니다.
- 학생 비밀번호는 암호화(SHA-256)해 저장하고, 10번 틀리면 15분 잠깁니다. 교사 비밀번호는 10분에 8번 틀리면 10분 막힙니다.
- 기준표·관찰 메모·특기사항 초안은 학생에게 보내지 않습니다.
- 예시 학생 두 명과 예시 속 숫자(○ 표시)는 형식을 보여 주려고 만든 것입니다.
- 특기사항 글자 수(`NOTE_LIMIT`, 진로활동 700자)는 해당 학년도 학교생활기록부 기재요령으로 확인합니다. 실제 기록은 선생님이 관찰한 사실로 씁니다.
